# 2048 Game - Classic Tile-Matching Puzzle

A fully functional, interactive web implementation of the classic 2048 puzzle game. The objective is to slide numbered tiles on a grid to combine them and reach the ultimate 2048 tile. This project heavily relies on complex JavaScript logic for matrix manipulation, state management, tile merging algorithms, and smooth CSS animations for a polished user experience.

## 🚀 Live Preview

Experience the game here: [Live Demo](https://dpdpodudu.github.io/2048-game/)

## 💻 Technologies Used

**Core:**
* **JavaScript (ES6+)** – Core game mechanics, matrix state management, event listeners, and dynamic DOM rendering
* **SCSS** – Advanced styling, responsive grid layout, and smooth tile-sliding animations
* **HTML5** – Semantic game board structure

**Architecture & Tools:**
* **BEM Methodology** – (Block, Element, Modifier) for maintainable and scalable CSS architecture
* **npm** – Package manager
* **Build Tools** – Local development server and production bundling
* **GitHub Pages** – Hosting and deployment
